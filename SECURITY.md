# Security Policy

## Scope

This is a static, client-side application. It does not include a backend or an account system.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository, or contact the repository maintainer privately through a verified contact method listed on the GitHub profile.

Include the affected browser, steps to reproduce, expected behavior, and potential impact. Do not include private audio files or other personal data.
